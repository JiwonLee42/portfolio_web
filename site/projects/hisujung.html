Stack and why기술 스택

  • Flask: The recommender is a separate Python server, apart from the Spring backend.
  • Cosine similarity: Measures how similar activities and users’ interests are, to rank recommendations.
  • AWS: Hosts the service so it can run as a deployed app.
  • Spring Boot, Spring Security, MySQL: Backend API, authentication, and data storage (teammates’ backend part).
  • Flask: 추천 로직을 Spring 백엔드와 분리된 파이썬 서버로 구성하기 위해 사용
  • Cosine similarity: 활동 간 유사도를 계산해 추천 순위를 정하기 위해 사용
  • AWS: 서비스를 배포해 실제 앱으로 동작시키기 위해 사용
  • Spring Boot, Spring Security, MySQL: 백엔드 API, 인증, 데이터 저장 구성(백엔드 팀원 담당)
