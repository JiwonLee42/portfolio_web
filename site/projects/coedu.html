Stack and why기술 스택

  • Spring Boot: Backend API server for members, boards, and schedules.
  • JWT: Token based authentication, with a token reissue API for expired access tokens.
  • Kakao Calendar API: Links board schedules to the members’ Kakao calendars.
  • Spring Boot: 회원, 게시판, 일정 API를 제공하는 백엔드 서버 구성
  • JWT: 토큰 기반 인증을 위해 사용, 만료된 액세스 토큰은 재발급 API로 갱신
  • Kakao Calendar API: 게시판 일정을 멤버의 카카오 캘린더와 연동하기 위해 사용
