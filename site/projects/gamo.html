Stack and why기술 스택

  • Spring Boot, JPA, MySQL: Base of the backend APIs and data storage for calls and history.
  • WebSocket: Exchanges call request, accept, end, and WebRTC signaling messages in real time.
  • WebRTC: Sends video and audio directly between participants without relaying through the server.
  • FastAPI AI server: The topic and keyword recommendation runs on a separate AI server, called from Spring Boot with retries.
  • Google Speech To Text: Converts recorded speech into text.
  • Jenkins, GCP: Automates build and deployment of the service.
  • Spring Boot, JPA, MySQL: 통화와 통화 기록 API, 데이터 저장을 위한 백엔드 기본 구성
  • WebSocket: 통화 요청, 수락, 종료와 WebRTC 시그널링 메시지를 실시간으로 주고받기 위해 사용
  • WebRTC: 영상과 음성을 서버 중계 없이 참여자끼리 직접 주고받기 위해 사용
  • FastAPI AI server: 통화 주제와 키워드 추천을 별도 AI 서버로 분리하고, Spring Boot에서 재시도하며 호출하기 위해 사용
  • Google Speech To Text: 녹음한 음성을 텍스트로 변환하기 위해 사용
  • Jenkins, GCP: 서비스 빌드와 배포 자동화를 위해 사용

What I did역할

  • Implemented the video call feature and the WebSocket signaling handler.
  • Implemented the 90 second call timeout and the 10 second wait before ending a call after a disconnect.
  • Implemented the call history API and screen.
  • Implemented the call of the AI server for topic and keyword recommendation, with up to 3 retries.
  • Implemented the recording and speech-to-text API.
  • Implemented the Jenkins build and deploy pipeline.
